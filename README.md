# Yonatan N. Degefu — Academic Website

Research, publications, and education in computational biology and systems pharmacology.

[Website](https://yonaneg.github.io/)

## Local preview

Use Node 24 LTS.

```sh
npm ci --ignore-scripts
npm run dev
```

Edit pages in `src/pages/` and publication records in `src/data/publications.ts`.
